APPROACH
--------

The original Playwright-based scraper failed due to proxy tunnel issues in
this environment. Curl works correctly with the proxy, so the scraper was
rewritten to use curl via child_process.

KEY INSIGHT: Algolia Batch Filtering
------------------------------------
Algolia's standard search pagination is limited to 1000 results. However,
by using the `facets` feature to get all batch names, then filtering by
each batch individually, we can retrieve ALL companies:

1. Fetch batch list using facets: {"facets": ["batch"]} returns 48 batches
2. For each batch, filter: {"filters": "batch:\"Winter 2022\""}
3. Within each batch, standard pagination works (max ~400 companies/batch)
4. Result: All 5,668 companies retrieved
